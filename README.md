# Stupid Ideas Hackathon

[Threadcheck](threadcheck/README.md): an Expo authenticator where your daily outfit and two snacks unlock real TOTP codes. Includes phone camera scans, USB/Bluetooth store-scanner input, biometric morning confirmation, local Supabase storage, and Backboard photo checks.

[Entré login demo](login-demo/README.md): a Next.js + Tailwind companion website with real Supabase password sign-in, QR authenticator enrollment, and TOTP verification. Run it at `http://localhost:3020` to use your authenticator app with a real two-factor login.
